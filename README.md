# Crosshair Overlay

**Прицел поверх игры.** Программа рисует прицел ровно по центру экрана игры STALZONE (Stalcraft) или любой другой игры. В саму игру она не лезет: это просто прозрачная картинка поверх окна.

Сделал **Neyron**. Вопросы и предложения пишите в Discord: **neyron**.

---

## Как начать (3 шага)

1. Скачайте `CrosshairOverlay.exe` со страницы [Releases](https://github.com/NeyronC/crosshair-overlay/releases/latest).
2. Запустите его. Откроется окно настроек, а в трее (возле часов) появится значок с прицелом.
3. Зайдите в игру. Прицел появится по центру.

Если Windows пишет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.

Если программа не запускается и просит .NET, установите **[.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0)** (раздел «.NET Desktop Runtime»).

## Что умеет

- **Свой прицел.** Можно собрать из фигур (крест, точка, круг, T-образный), нарисовать по пикселям или загрузить картинку PNG, SVG или **GIF-анимацию**.
- **Пресеты.** Сохраняйте сколько угодно прицелов и переключайтесь между ними. У каждого прицела может быть **своя клавиша**, например `C+3`.
- **Сброс стандартных прицелов.** Кнопка со стрелкой ↶ возвращает стандартный прицел к исходному виду. Кнопка «Вернуть удалённые стандартные прицелы» восстанавливает удалённые.
- **Реакция на выстрел (ЛКМ):**
  - *Разлёт*: крест расходится, пока вы стреляете, и сходится обратно. Насколько и как быстро, настраивается.
  - *Цвет при стрельбе*: прицел меняет цвет, пока зажата ЛКМ.
  - *GIF*: анимация играет всегда, только пока зажата ЛКМ или один раз на каждый клик.
  - Проверить можно прямо в настройках: зажмите ЛКМ на превью.
- **Прячется сам:**
  - когда вы переключились из игры (Alt+Tab, свернули);
  - когда в игре открыто меню, инвентарь или карта (виден курсор мыши);
  - по желанию — пока зажата ПКМ (прицеливание).
- **Горячие клавиши.** Можно «скрыть/показать», «следующий прицел» и свою клавишу для каждого прицела. Подходят любые сочетания: `Ctrl+Alt+X`, `C+3`, `Shift+Mouse4`.
- **Автозапуск с Windows** и **низкая нагрузка.** В фоне программа работает с самым низким приоритетом и занимает около 10 МБ памяти.

## Это безопасно для античита?

Программа **не трогает игру**: не читает и не меняет её память, не внедряется в процесс и не перехватывает графику. Она только смотрит, какое окно активно, где оно на экране и виден ли курсор. Потом рисует свою прозрачную картинку поверх. Так работают обычные оверлеи вроде Discord.

Гарантию за конкретный античит не даст никто, но программа не делает ничего, за что обычно банят.

## Частые проблемы

### Прицел не видно в полноэкранном режиме

Это самая частая проблема. В полноэкранном режиме видеокарта может выводить игру на монитор напрямую, и Windows не может показать поверх неё другие окна.

**Самое простое решение для любой видеокарты:** в настройках игры поставьте режим экрана **«В окне без рамки»** (в STALZONE — «В окне без рамки (режим совместимости)») или **«В окне»**. Там прицел виден всегда.

**Видеокарта NVIDIA.** Программа сама пробует это исправить (флажок «Автоматически настраивать драйвер NVIDIA» в разделе «Поведение», включён по умолчанию). Она меняет в драйвере одну настройку только для игры. **После этого игру нужно перезапустить.** Если в настройках программы появилась кнопка «Применить с правами администратора», нажмите её. Сделать то же вручную: Панель управления NVIDIA → Управление параметрами 3D → Программные настройки → `stalzonew.exe` → «Метод представления Vulkan/OpenGL» → «Предпочтительно многослойный на цепочке DXGI».

**Видеокарта AMD (Radeon) или Intel.** Автоматической настройки драйвера для них нет. Используйте режим **«В окне без рамки»**. Это нормально: по FPS разница обычно в пределах пары кадров.

### Прицел вообще не появляется

- Проверьте внизу слева в окне программы, включён ли «Прицел включён».
- Откройте раздел «Окно игры». В поле «Процесс» должно быть `stalzonew.exe`. Если сомневаетесь, нажмите «Выбрать кликом» и щёлкните по окну игры.
- Посмотрите на строку состояния. «Курсор виден — скрыт» значит, что в игре открыто меню: закройте его. «Скрыт горячей клавишей» значит, что вы нажали клавишу скрытия: нажмите её ещё раз.
- Если не помогло, перезапустите программу (правый клик по значку в трее → «Выход», затем запустите снова).

### Прицел пропадает, когда я целюсь или открываю инвентарь

Так задумано. Это отключается в разделе «Поведение»: флажки «Скрывать прицел, когда виден курсор» и «Скрывать прицел, пока зажата ПКМ».

### Прицел чуть не по центру

В разделе «Прицел» → «Смещение от центра» его можно сдвинуть по пикселю влево/вправо и вверх/вниз.

### Горячая клавиша не срабатывает

- Клавиши работают, **только когда активно окно игры**: так сделано специально, чтобы не мешать в других программах.
- Если одно сочетание входит в другое (например, `3` и `C+3`), срабатывает более длинное.
- Программа не забирает нажатия у игры: игра их тоже получает. Выбирайте сочетание, которое в игре ничего важного не делает.

### Автозапуск перестал работать

Если вы переместили `CrosshairOverlay.exe` в другую папку, выключите и снова включите «Запускать вместе с Windows».

### Я сломал стандартный прицел

Выберите его и нажмите кнопку ↶ («Сбросить») над списком прицелов. Если удалили совсем, нажмите «Вернуть удалённые стандартные прицелы».

### Где лежат мои настройки

`%APPDATA%\CrosshairOverlay` (вставьте эту строку в адресную строку Проводника). Там `settings.json` с прицелами, папка `images` с картинками и `error.log`, если что-то пошло не так. Если пишете о проблеме в Discord, приложите `error.log`.

## Для разработчиков

Код на C# (.NET 10, WPF). Оверлей — отдельное Win32-окно `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOPMOST | WS_EX_NOACTIVATE`, картинка выводится через `UpdateLayeredWindow`.

Сборка:

```bash
cd src
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o ../dist
```

Самопроверка рендера и анимации: `CrosshairOverlay.exe --selftest result.txt`.

| Файл | Что внутри |
|---|---|
| `OverlayWindow.cs` | прозрачное окно поверх игры |
| `WindowTracker.cs` | следит за окном игры, курсором и кнопками мыши |
| `CrosshairRenderer.cs` | рисует прицел попиксельно, загружает PNG/SVG/GIF |
| `CrosshairAnimator.cs` | анимация GIF и реакция на выстрел |
| `Hotkeys.cs` | сочетания клавиш вроде `C+3` |
| `NvidiaProfile.cs` | настройка драйвера NVIDIA через NVAPI |
| `Models.cs` | прицелы и настройки, сохранение в JSON |
| `MainWindow.xaml` | окно настроек |
